# [Backstage](https://backstage.io)

This is your newly scaffolded Backstage App, Good Luck!

To start the app, run:


export variables for my GitHub Client access:

```
export AUTH_GITHUB_CLIENT_ID="your_client_id_here"
export AUTH_GITHUB_CLIENT_SECRET="your_client_secret_here"
```


and finally start IDP:


```sh
nvm use 24

yarn install
yarn start
```

Backstage is running under <http://localhost:3000/>
